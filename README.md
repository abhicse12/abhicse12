### 🔹 EchoVerse — AI-Powered Community Discussion Platform
Reddit-inspired platform with communities, nested comments, upvote/downvote, AI-generated post titles & summaries via **Groq AI**, secure auth with **Clerk**, and a Prisma + PostgreSQL (Supabase) backend. Deployed on Vercel with SSR & infinite scroll.

### 🔹 Transcripto — AI-Powered Speech-to-Text SaaS
Upload or record audio in-browser and get accurate transcriptions via **AssemblyAI**. MVC backend with Express + Multer, MongoDB Atlas storage, Clerk auth, and a dark premium SaaS UI.

### 🔹 MeterFlow — API Management & Billing Platform
API gateway with key validation, Redis-based rate limiting, JWT auth, per-key usage analytics, and a Razorpay-powered usage-based billing engine.

### 🔹 Weather App — Dockerized & Deployed
Node.js backend proxy securing OpenWeather API keys, containerized with Docker, deployed on Render.
